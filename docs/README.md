# Dokumentit: luvat, juridiikka ja sopimuspohjat

Tämä kansio sisältää palvelun v1:n hallinnolliset ja juridiset pohjat. **Mitään hakemusta ei ole lähetetty.** Kaikki on luonnosta, joka viimeistellään ja lähetetään vasta kun Eetu antaa luvan.

Palvelun rooli kaikissa dokumenteissa: **pelkkä ilmoitus- ja kohtaamisalusta**. Emme ole kiinteistönvälittäjä, emme ota toimeksiantoja emmekä toimi kenenkään lukuun kaupassa. Kauppa tehdään osapuolten kesken Maanmittauslaitoksen Kiinteistökaupan verkkopalvelussa (tai kaupanvahvistajan luona).

Yritys: **[Yrityksen nimi], Y-tunnus 3552285-3**. Hakasulkeissa `[...]` olevat kohdat täytetään ennen lähettämistä tai julkaisua.
